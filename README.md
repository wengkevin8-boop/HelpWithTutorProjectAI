HelpWithTutor

AI powered tutoring planner app, where users sign up and enter a 
subject/topic/level/goal and get a Gemini powered tutoring planner, 
quiz, or concept explanation, which will be saved to their history.

Generation Powered by AI

- Learning Plans: Produce tutoring plans on a weekly basis, which comprise the goals, 
                  activities, resources, and evaluation methods.
- Automatic Quizzes: Formulate multiple-choice queries that have the 
                     right answers and the explanation of the correct ones.
- Concept Explanation: Get of the explanation of the concepts in details using analogies, 
                       key points, misconception warnings, and next moves.
- Inputs that are Adjustable: Select subjects, themes, and levels (Elementary/Middle/Advanced) 
                              and aims of learning.

Management of Users and Their Security
- Authentication that is secure based on JWT (HTTP-only cookies), and passwords would secure it
  by using MongoDB.

User profile editing (username, email)
- Deleting accounts along with deleting learning plans
- Management of History and Data
- Keeping all the operations in the history of the user
- Filtering history into types of operations
- Displaying the information in the scrollable model
- Deleting the tasks that are not required.

Frontend and UI/UX
- Modern dark background UI 
- Fonts used: Oswald and Inter
- Interesting hover effects that are applied for feature cards
- Toast notifications for the messages received
- Loading spinners for operations

Prerequisites

- Node.js (LTS recommended)
- A MongoDB database (local or MongoDB Atlas)
- A Google Gemini API key (Google AI Studio)

Backend

- Node.js & Express.js
- Mongoose (MongoDB ODM)
- JSON Web Tokens (JWT)
- EJS (Embedded JavaScript templating)
- Google Generative AI SDK (@google/generative-ai - Gemini 1.5 Flash)

Frontend

- HTML5 / Vanilla JavaScript (ES6+)
- Tailwind CSS (via CDN)
- Lucide Icons (via CDN)

Database:
